# Aroma & Crust Artisan Cafe — Modern Responsive Website

A responsive, multipage culinary website for **Aroma & Crust Artisan Cafe**, specializing in handcrafted wood-fired pizzas, 100% prime Angus smash burgers, and specialty organic coffee.

## 🚀 Key Features

- **Modern Responsive Design**: Fluid layout tailored for mobile, tablet, and desktop screens with custom navigation and interactive cart.

## 📂 Project Structure

- `index.html` — Homepage with Hero, Menu Highlights, Products, About, Testimonials, Interactive FAQ, and Blog.
- `about.html` — The story of our sourdough fermentation, flame-kissed grilling, and artisan philosophy.
- `menu.html` — Complete food and beverage menu with structured pricing.
- `products.html` — Signature prime smash burgers with detailed nutritional info.
- `review.html` — Verified customer reviews and 5-star ratings.
- `faq.html` — Dedicated Frequently Asked Questions page with Schema.org FAQPage structured data.
- `cart.html` — Dedicated Shopping Cart page with real-time order summary, quantity controls, and checkout flow.
- `contact.html` — Interactive contact and table reservation form with Google Maps integration.
- `blog.html` — Culinary articles and baking guides from our chefs and baristas.
- `style.css` — Custom styling, CSS variables, grid systems, and animations.
- `script.js` — Mobile menu drawer, search toggle, shopping cart preview, and FAQ accordion.
- `image/` — Web-optimized food photography and graphic assets.

## 💻 How to Run Locally

Open `index.html` in any modern web browser or serve via Live Server / local web server.
